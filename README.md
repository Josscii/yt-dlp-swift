# YTDLPSwift

A Swift implementation for YouTube video information extraction, inspired by yt-dlp. This library provides functionality to extract video metadata, multiple video resolutions, different audio bitrates, and subtitle information from YouTube URLs.

## Features

- 🎥 **Video Information Extraction**: Get comprehensive metadata including title, uploader, description, duration, and view count
- 📱 **Multiple Video Formats**: Support for different resolutions and quality options
- 🎵 **Audio Format Support**: Extract audio-only streams with different bitrates
- 💬 **Subtitle Extraction**: Access available subtitles in multiple languages
- ✅ **URL Validation**: Robust YouTube URL validation and video ID extraction
- 🧪 **Comprehensive Testing**: Full test coverage for all functionality
- 🚀 **Swift Package Manager**: Easy integration with SPM

## Installation

Add this package to your `Package.swift` file:

```swift
dependencies: [

]
```

## Quick Start

```swift
import YTDLPSwift

let extractor = YouTubeExtractor()

// Validate YouTube URL
if extractor.isValidYouTubeURL("https://www.youtube.com/watch?v=dQw4w9WgXcQ") {
    print("Valid YouTube URL")
}

// Extract video ID
if let videoId = extractor.extractVideoId(from: "https://youtu.be/dQw4w9WgXcQ") {
    print("Video ID: \(videoId)")
}

// Extract complete video information
do {
    let videoInfo = try await extractor.extractVideoInfo(from: "https://www.youtube.com/watch?v=dQw4w9WgXcQ")
    
    print("Title: \(videoInfo.title)")
    print("Uploader: \(videoInfo.uploader ?? "Unknown")")
    print("Duration: \(videoInfo.duration ?? 0) seconds")
    
    // Available video/audio formats
    for format in videoInfo.formats {
        if format.isVideoOnly {
            print("Video: \(format.resolution ?? "Unknown") - \(format.videoBitrate ?? 0)kbps")
        } else if format.isAudioOnly {
            print("Audio: \(format.audioBitrate ?? 0)kbps")
        } else {
            print("Combined: \(format.resolution ?? "Unknown") - V:\(format.videoBitrate ?? 0)kbps A:\(format.audioBitrate ?? 0)kbps")
        }
    }
    
    // Available subtitles
    for subtitle in videoInfo.subtitles {
        print("Subtitle: \(subtitle.languageName) (\(subtitle.language))")
    }
} catch {
    print("Error: \(error)")
}
```

## Data Structures

### VideoFormat
Represents different quality and format options for video/audio streams:

```swift
public struct VideoFormat {
    public let formatId: String          // Format identifier
    public let url: String               // Download URL
    public let resolution: String?       // Video resolution (e.g., "1280x720")
    public let width: Int?               // Video width in pixels
    public let height: Int?              // Video height in pixels
    public let fps: Int?                 // Frames per second
    public let videoBitrate: Int?        // Video bitrate in kbps
    public let audioBitrate: Int?        // Audio bitrate in kbps
    public let audioSampleRate: Int?     // Audio sample rate in Hz
    public let fileSize: Int64?          // File size in bytes
    public let container: String?        // Container format (mp4, webm, etc.)
    public let videoCodec: String?       // Video codec
    public let audioCodec: String?       // Audio codec
    public let isVideoOnly: Bool         // Video-only stream
    public let isAudioOnly: Bool         // Audio-only stream
}
```

### Subtitle
Represents subtitle track information:

```swift
public struct Subtitle {
    public let language: String          // Language code (e.g., "en")
    public let languageName: String      // Human-readable language name
    public let url: String               // Subtitle file URL
    public let format: String            // Subtitle format (vtt, srt, etc.)
    public let isAutoGenerated: Bool     // Whether subtitles are auto-generated
}
```

### VideoInfo
Complete video metadata container:

```swift
public struct VideoInfo {
    public let id: String                // Video ID
    public let title: String             // Video title
    public let description: String?      // Video description
    public let uploader: String?         // Channel/uploader name
    public let uploadDate: String?       // Upload date
    public let duration: Int?            // Duration in seconds
    public let viewCount: Int64?         // View count
    public let likeCount: Int64?         // Like count
    public let thumbnail: String?        // Thumbnail URL
    public let formats: [VideoFormat]    // Available formats
    public let subtitles: [Subtitle]     // Available subtitles
}
```

## Error Handling

The library provides comprehensive error handling through the `YouTubeExtractorError` enum:

```swift
public enum YouTubeExtractorError: Error {
    case invalidURL                      // Invalid or non-YouTube URL
    case videoIdNotFound                 // Could not extract video ID
    case failedToDecodeHTML             // HTML parsing failed
    case formatExtractionFailed         // Format extraction failed
    case networkError(Error)            // Network-related error
}
```

## Technical Notes

This implementation provides a foundation for YouTube video information extraction. The current version includes:

- ✅ URL validation and video ID extraction
- ✅ Data structure definitions for all metadata types
- ✅ Comprehensive test coverage
- ✅ Example implementation

For production use, you would need to implement the actual YouTube page parsing and format extraction logic, which involves:

1. Downloading YouTube video pages
2. Parsing JavaScript player code
3. Extracting and decrypting streaming URLs
4. Handling YouTube's anti-bot measures
